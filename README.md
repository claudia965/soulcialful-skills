# Soulcialful Skills für Claude Code

Skills, mit denen ich meinen eigenen Content mache. Zum Kopieren, Anpassen, Weiterbauen.

## anti-ki-floskel

Prüft einen Text auf KI-Floskeln und typische KI-Muster, die LinkedIn und Instagram als KI-generiert erkennen, und schreibt die Stellen menschlich um. Zeigt pro Treffer, was die Floskel ist, warum sie auffällt und wie es besser klingt.

Funktioniert mit jedem Text: Caption, LinkedIn-Post, Blog, Newsletter, Mail.

### Installieren

1. Den Ordner `anti-ki-floskel` in deinen Projekt-Ordner unter `.claude/skills/` kopieren (oder global nach `~/.claude/skills/`).
2. Claude Code neu starten.
3. Text einfügen und schreiben: `/anti-ki` oder „klingt das nach KI?“

Die Regeln stehen in `anti-ki-floskel/references/regeln.md`. Dort kannst du eigene Nie-Wörter ergänzen.

### Was er findet

- die 8 Struktur-Muster von KI-Texten (zum Beispiel „Egal ob du X, Y oder Z bist“, Dreier-Listen mit gleichem Anfang, Schlusssatz wiederholt den Anfang)
- 6 Köder-Muster, die Plattformen aktiv abstrafen
- Gedankenstriche, Nie-Wörter, Füllwörter
- Texte ohne Ich, ohne Beispiel, ohne Meinung

Am Ende gibt es eine Tabelle mit allen Treffern, ein Urteil und auf Wunsch die entschärfte Vollversion.
